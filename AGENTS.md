# AGENTS.md

## О проекте
- Это чат-агент на Python для диалога с LLM в терминале.

## Рабочие правила для агентов
- Перед решением задачи сначала согласуй с пользователем краткий план.
- Если в задаче есть неоднозначность, сначала задай уточняющий вопрос пользователю, а не додумывай критичные детали.
- Перед изменением кода сначала изучи затронутые файлы и связанные тесты.
- Сохраняй текущий стиль проекта: простые решения, явные имена, минимум лишней абстракции.
- Не добавляй новые зависимости без явной необходимости.
- Если меняешь существующее поведение, обновляй или добавляй тесты.

## Что проверять после изменений
- Для изменений CLI: `pytest -q tests/test_cli_tokens.py`
- Для изменений хранилища или токенов: `pytest -q tests/test_storage_tokens.py tests/test_cli_tokens.py`
- Для изменений компрессии контекста: `pytest -q tests/test_context_compression.py`
- Для сквозных изменений поведения: `pytest -q`

## Особенности проекта
- Не трогай пользовательские данные и локальные артефакты без прямой необходимости.
- Live-тесты должны запускаться только при явном флаге `--live-model-tests`.

## Ожидания к изменениям
- Любое изменение пользовательского поведения должно сопровождаться тестом или корректировкой существующего теста.
- Если задача неоднозначна, не принимай важные решения молча: сначала уточни их у пользователя.
